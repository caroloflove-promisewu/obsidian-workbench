# Personal Workbench · Obsidian 插件

移动端优先的个人工作台，**直接读写本地库，零后端**。四大端（iPhone / iPad / Windows 桌面 / Windows 笔记本）通过坚果云同步同一份 vault，天然一致。

当前版本 **0.4.1**。

## 快速记录（0.3.0 回归网页版模型）

**一条笔记 = 一个独立文件**，不是往当天文件里追加。文件名 `YYYYMMDDHHmm｜标题｜关键词.md`，
存在暂存筐目录下，内容套用「卡片盒 · 信息卡」模板：

```markdown
- 正文写在这里

#### 关联思考：
- **链接到：** 
- **引出问题：**
- **可行的行动：**
- **潜在思考主题：**
```

首页输入区：**内容** + **标题 T / 关键词 K**（常显）+ **关联思考三项**（可折叠），
外加「仅新建空白卡」按钮。同时间戳重名自动追加 `-2` `-3`，绝不覆盖。

- 模板可自定义：设置里填「快速记录模板」路径，或点「把内置信息卡模板写入库」生成一份再改
- 标题/关键词留空时，文件名保留字面字母 `T` / `K`（方便日后回补）
- 旧版按天追加的 `02暂存筐/<日期>.md` 文件仍原样保留，只是不再新增

## 界面风格

界面沿用早期**网页版工作台的浅色 App 观感**：浅灰底 + 白色圆角卡片 + 极轻阴影 + 蓝色主按钮 + 行列表式清单项。
实现方式是在 `styles.css` 里把 Obsidian 主题变量**重定向**到工作台自己的色板，因此：

- **浅色 / 深色两套配色**，跟随 Obsidian 的 `.theme-light` / `.theme-dark` 自动切换
- 换肤不依赖逐条改样式，将来想还原成「完全跟随 Obsidian 主题」，删掉两个 `.theme-* .wb-root` 变量块即可
- 色值取自 Apple 系统色板（`#f5f5f7` / `#ffffff` / `#0a84ff` / `#34c759` / `#ff9500` / `#ff3b30`）

|---|---|---|

| 日程 | ✅ | 周/月/列表三视图、格内新增/勾选、重复规则；手机端周视图可横滑并自动滚到今天 |

| 清单 | ✅ | 学习清单 / AI 练习清单、分节、勾选落盘 |
| 搜索 | ✅ | 文件名 + 全文匹配、命中高亮、一键打开 |

> 首页刻意保持克制：在网页版「快速记录 / 今日日程」基础上，加了「番茄钟」和精简的「打卡」。
> 更完整的统计在各自的标签页里（进度条 → 项目页，热力图与月度统计 → 打卡页）。
>
> **0.4.1 起首页排序改为 番茄钟 → 打卡 → 快速记录 → 今日日程**：番茄钟和打卡都是「每天要点一下」的，
> 放上半屏最顺手；手机上一屏就能看到打卡。

### 番茄钟（0.3.0 新增）

- **自定义时长**：预设 15 / 25 / 45 / 60 分钟，也能手填 1–180 任意整数（`设定` 按钮或回车）
- **专注 → 休息自动衔接**，完成后进入 5 分钟休息（时长可在设置里改）
- **暂停 / 继续 / 重置**；专注中改时长不会打断当前这一轮
- 表盘进度环实时反映剩余比例，专注（蓝）/ 暂停（橙）/ 休息（绿）三态换色
- 完成后可选**写一条记录进今日日程**（`🍅 专注 N 分钟`，`due::` 为今天），
  默认开启，可在卡片上或设置里关掉

> 计时状态**刻意不落盘**：关掉工作台/重开卡片会回到待机，不会"偷跑"。
> 完成记录才落盘，且写进**今天**的日程段（不是收件箱）——所以它天然能进你已有的日程与统计体系，不新增数据格式。

## 项目笔记与待办（0.4.0）

项目卡片现在是两层：**待办** + **项目笔记**。原来的「成果要求」和「节点」都去掉了。

### 待办 = 待办 + 日期

一条待办就是一行 Markdown，日期直接写在行尾：

```markdown
## 待办
- [ ] 收集竞品资料
- [ ] 定下包装方案 📅 2026-12-20
- [x] 立项评审 📅 2026-08-01
```

- **有日期** → 往日程写一条 `项目名·待办`，日期为那天；改日期是更新同一条，不是新增
- **没日期** → 只留在项目里，不进日程。想把无日期的挪进日程，点日期胶囊补一个就行
- 日期胶囊**过期变红、今天蓝色、未来灰色**；已完成的不标红
- 打卡卡片上的「已排期 N」= 带日期且未完成的条数

> 老版本的 `里程碑:` frontmatter 会在启动时**自动迁移成带日期的待办**（同名待办已存在就跳过，可重复执行）。

### 项目笔记：折叠只看标题，点一下跳正文

格式固定为三级标题 + 时间戳，最新的一条在最上面：

```markdown
## 项目笔记
### 2026-10-19 10:32 · 和供应商敲定打样时间
对方答应周四出样，先做 3 版手感对比。
另外确认了起订量 500 起。

### 2026-10-12 15:08 · 竞品价格带梳理
主流区间集中在 89–129 元。
```

- **时间戳自动写**（`YYYY-MM-DD HH:mm`，本地时区），**关键词标题你手写**
- **折叠时只显示「时间戳 · 标题」一行**，展开才显示正文摘要（每条最多 120 字，超出省略）
- **点任意一条** → 在 Obsidian 里打开这个项目的 md 文件，**滚动到那一段并定位**（行号换算已算上 frontmatter）
- 「＋ 记一条」弹窗里标题回车就能跳到正文，正文是多行文本框，换行原样保留
- 笔记全存在项目 md 文件里，没有额外数据文件；手机上也能直接看

## 开发

```bash
pnpm install          # 安装依赖
pnpm dev              # watch 构建
pnpm build            # 类型检查 + 生产构建
pnpm test             # 全量测试（9 个脚本，820 项）
```

产物为 `main.js`（esbuild 打成 CJS，`obsidian` 保持 external）。

生成可看的 HTML（在 `tests/` 下）：

```bash
node tests/make-preview.js   # → /workspace/预览/工作台预览.html   静态六页预览
node tests/make-demo.js      # → /workspace/演示/工作台演示.html   可操作演示（真代码 + 内存 vault）
```

## 安装到 vault

把 `manifest.json`、`main.js`、`styles.css` 三个文件放进：

```
<你的库>/.obsidian/plugins/obsidian-workbench/
```

然后在 Obsidian「设置 → 第三方插件」里启用。

## 手机速记（无需后端）

插件注册了自定义协议 `obsidian://workbench`：

```
obsidian://workbench?action=addNote&text=买牛奶&title=采购&keyword=生活
obsidian://workbench?action=addNote&text=想法&question=为什么&actionItem=先试一版
obsidian://workbench?action=addTodo&text=写第二章&project=07工作台/03项目/年终总结.md
obsidian://workbench?action=addSchedule&text=交报告&date=2026-03-10
obsidian://workbench?action=open&tab=projects
```

`addNote` 支持的参数与首页四组输入框一一对应：`text`（正文）/ `title`（T）/ `keyword`（K）/ `question`（引出问题）/ `actionItem`（可行的行动）/ `theme`（潜在思考主题）/ `stamp`（自定义时间戳，默认取当前时刻）。

设置面板里这四条链接**点一下就能复制**，直接粘进 iOS 快捷指令。

兜底（不依赖插件）：`obsidian://new?file=02暂存筐/速记&content=...&append=true`

## 数据约定

默认目录（**0.3.1 起**，均可在设置里改）：

| 用途 | 默认路径 |
|---|---|
| 项目卡片 | `07工作台/03项目/` |
| 日程、习惯打卡、清单 | `07工作台/04打卡/` |
| 快速记录暂存筐 | `02暂存筐/`（仍在库根，未收进 `07工作台`） |

> 从 0.3.0 及更早升级时，若你**没有手动改过**这两个目录，插件会自动把 `03项目` / `04打卡` 迁移到 `07工作台/` 下；**自己改过路径的不会被覆盖**。

- 日程存**单文件** `<打卡目录>/日程.md`，按 `## YYYY-MM-DD` 分段
- 条目用行内字段：`due::` / `time::` / `repeat::` / `id::` / `source::` / `done::`
- 重复条目完成状态按日期存（`done::2026-03-04,2026-03-11`）
- 项目 = `<项目目录>/*.md`，frontmatter 存状态，正文 `## 待办`（行尾 `📅 YYYY-MM-DD` 表示计划日期）+ `## 项目笔记`（`### YYYY-MM-DD HH:mm · 标题` 分段）
- 习惯 = `<打卡目录>/习惯打卡.md`，`## 习惯名` 段下 `- YYYY-MM-DD` 即打卡记录
- **日期一律本地时区**，绝不用 `toISOString()`

## 版本记录

- **0.4.1** — 首页与项目页两处优化：
  1. **项目板块新增搜索栏**：常驻在列表上方，**只匹配项目名称**（不搜待办正文和笔记 —— 那样结果会变得不可预期），不区分大小写、支持中文子串；**就地过滤、保留卡片样式**，计数变成「找到 N 个 / 共 M 个」；有词时右侧出现清空按钮（`Esc` 也能清），搜不到时给出空态并回显关键词；过滤时批量的「全选」只作用于过滤结果（避免搜出 3 个却全选了 30 个）；搜索框不参与列表重绘，输入不丢焦点，**切到别的标签页再回来关键词还在**；输入做了 120ms 合并，打字时不会每按一键就重排一次。
  2. **番茄钟缩量 + 打卡上移**：番茄钟从「一根竖条」改成**矮宽模块** —— 容器够宽时表盘在左、番茄数与操作在右，容器窄（手机）时退回竖排；表盘 152 → 104px、时长设定默认**折叠**（标题右侧「时长 ▾」展开），桌面高度 **308 → 204px**、手机 **386 → 328px**。首页顺序改为 **番茄钟 → 打卡 → 快速记录 → 今日日程**，四端都做到「打卡在一屏内可见」。
  实现上踩到两个坑，记在这里备查：其一，**容器查询改不了容器自身的布局**，`.wb-pomo` 既当查询容器又当被改对象会完全不生效（高度死活不变），必须拆成外层 `.wb-pomo-cq` + 内层 `.wb-pomo`；其二，宽容器里 `side` 在 DOM 中排在表盘之前，只给 `grid-area` 会被自动放置摆到左边的列，**必须显式写 `grid-column`**。另外 `@container` 块要写在被覆盖的选择器**之后**，否则 `padding` 会被后面的普通规则吃掉。
- **0.4.0** — 项目板块重构，三处改动：
  1. **去掉「成果要求」**（frontmatter 字段仅为兼容保留，界面上不再显示）；
  2. **去掉「节点」**，与待办合并 —— 待办的日期写在行尾 `📅 YYYY-MM-DD`，**有日期就同步一条到日程，没日期只留在项目里**；改日期更新同一条、清空日期会移除日程条目；老 `里程碑:` 启动时自动迁移成带日期的待办（幂等）；文件里原本就带日期的待办，打开项目页时会做一次兜底同步进日程。
  3. **新增「项目笔记」**：每条 `### YYYY-MM-DD HH:mm · 关键词标题`，时间戳自动生成、标题手写，**最新在上**；列表**可折叠，折叠时只显时间戳 + 标题**，展开显正文摘要；**点一行直接打开项目 md 并定位到那一段**。
  UI 细节：待办日期胶囊（过期红 / 今天蓝 / 未来灰）；日期框图标左置、文本居中，窄屏不再被压成 `…`；笔记行操作按钮改为绝对定位，行高从 65px 收到 30px。
